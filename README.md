# Labs: Enterprise Architecture with Generative AI (FIAP)

1. **Comece aqui:** [docs/guia_codespace.md](docs/guia_codespace.md), passo a passo da conta no GitHub ao primeiro exercício.
2. Resumo para o operador: "Use this template" → repositório privado do grupo → Code → Codespaces → Create codespace → `claude` (login) → `make check` ([docs/checklist_operador.md](docs/checklist_operador.md)).
3. Cada lab: siga `labs/labN/README.md` e confira com `make labN-check`.
4. Problemas: [docs/faq.md](docs/faq.md). Cota acabou ou API falhou: use o replay em `replay/`.
5. Projeto integrador (avaliação): [integrador/README.md](integrador/README.md). Entregas pelo Portal do Aluno da FIAP.

Dados 100% sintéticos. Nunca grave chaves ou tokens no repositório.
