# Labs: Enterprise Architecture with Generative AI (FIAP)

1. **Comece aqui:** [docs/guia_codespace.md](docs/guia_codespace.md), passo a passo da conta no GitHub ao primeiro exercício. Com as telas, onde clicar: [docs/guia_ilustrado_codespace.md](docs/guia_ilustrado_codespace.md).
   **Operador com plano ChatGPT (Codex)?** Siga o [docs/guia_codex.md](docs/guia_codex.md): ele aproveita os passos 1 a 4 do guia do Codespace e troca o login e o jeito de abrir o agente.
2. Resumo para o operador: "Use this template" → repositório privado do grupo → Code → Codespaces → Create codespace → `claude` (login) → `make check` ([docs/checklist_operador.md](docs/checklist_operador.md)). Com Codex: `codex login --device-auth` no lugar de `claude` ([docs/guia_codex.md](docs/guia_codex.md)).
3. Cada lab: siga `labs/labN/README.md` e confira com `make labN-check`. Labs novos e correções chegam ao repositório do grupo com `make atualizar` (os arquivos do grupo não mudam). Com Codex, o Lab 1 tem o passo do agente em [labs/lab1/codex.md](labs/lab1/codex.md).
4. Problemas: [docs/faq.md](docs/faq.md). Cota acabou ou API falhou: use o replay em `replay/`.
5. Projeto integrador (avaliação): [integrador/README.md](integrador/README.md). Entregas pelo Portal do Aluno da FIAP.

Dados 100% sintéticos. Nunca grave chaves ou tokens no repositório.
