# Pacote do projeto integrador

Preencham os arquivos desta pasta e os ADRs em `docs/adr/` (skill `escrevendo-adrs`). Troquem
cada `PREENCHER`; os comentários `<!-- -->` podem ficar. Critérios em [../rubrica.md](../rubrica.md).

| `01-design.md` | Design (15) | Atividade 2: conhecimento e MCP; final: tudo |
| `02-qualidade.md` | Qualidade (10) | final |

| `04-seguranca.md` | Segurança e governança técnica (15) | final |

| `pitch.md` | condição para a arguição | final, 48h antes da Aula 4 |

Conferência: `make er-check`, `make checkpoint-check`, `make pacote-check`.
