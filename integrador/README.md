# Projeto integrador

A arquitetura do **Bússola**, assistente de IA de um banco fictício, construída ao longo das 4
aulas e entregue como trabalho final depois da Aula 4.

| Arquivo | Para quê |
|---|---|
| [caso.md](caso.md) | a instituição, o problema, os departamentos, os requisitos (RC-NN) e a regulação |
| [atividades.md](atividades.md) | o trabalho final: o que entregar, os passos e o prazo |
| [rubrica.md](rubrica.md) | como o trabalho final (o pacote) é avaliado |
| [pacote/](pacote/) | os modelos que o grupo preenche |
| `legado/` | o código do SGC, o sistema de cobrança; os fatos que importam estão no caso.md (`make legado` roda um ciclo) |

Comandos: `make trabalho`, `make trabalho-adr`, `make pacote-check` e `make trabalho-entregar`.
