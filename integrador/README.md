# Projeto integrador

A arquitetura do **Bússola**, assistente de IA de um banco fictício, construída ao longo das 4
aulas e defendida na Aula 4.

| Arquivo | Para quê |
|---|---|
| [caso.md](caso.md) | a instituição, o problema, os departamentos, os requisitos (RC-NN) e a regulação |
| [atividades.md](atividades.md) | as 3 atividades entre as aulas, com passos e prazos |
| [rubrica.md](rubrica.md) | como o pacote e a arguição são avaliados; categorias das cartas |
| [pacote/](pacote/) | os modelos que o grupo preenche |
| `legado/` | o SGC, sistema de cobrança para a engenharia reversa (`make legado` roda um ciclo) |

Conferência: `make er-check`, `make checkpoint-check`, `make pacote-check`.
